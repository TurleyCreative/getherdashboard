Letter Copy
Letter preview & edit step
When on, users see a formatted, editable version of their letter before submitting. When off, the form submits directly — best for simpler forms where you don't want users to see or change the letter.
Opening paragraph
The first line of the letter body, setting out why the person is writing. Appears directly after "Dear Officer" and the application reference.
Statement introduction line
Appears before the bullet list of selected support statements. Only shown in the letter if the user has ticked at least one statement.
Closing line
A call-to-action sentence that appears at the end of the letter, just before "Kind regards". Use it to make a direct request to the planning officer.
Comments box prompt
The instructional text shown above the free-text comments box on the form. Encourage users to add personal context — unique comments make each submission more effective.
Generate letter button text
The label on the first submit button. When the preview/edit step is on, this triggers letter generation. Leave blank to use the default.
Submit button text
The label on the final submit button — shown on the letter preview step (if enabled) or as the only button (if preview is off). Leave blank to use the default.

Must be an exact Google Fonts name. Leave blank to inherit the font from the page — ideal for Squarespace, Wix, or any CMS where the form is embedded in a code block. The form will then automatically use whatever font the website is already using.
